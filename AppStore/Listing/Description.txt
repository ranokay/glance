See what's in your files without opening them!

Glance boosts your productivity by providing Quick Look previews for files that macOS doesn't support out of the box.

Version 1.6.0 is built for Apple silicon Macs running macOS 26 or later.

Features:
• Beautiful file previews for various file types
• Previews visible in Quick Look, Finder and Spotlight
• Native macOS 26 controls and adaptive window materials
• Lazy, expandable folder trees with Finder-style icons, pagination, and progressive media thumbnails
• In-place previews and multi-level Back navigation for nested folder items
• A compatible-app Open With chooser that never changes default file associations
• Local preview processing with no telemetry or file-content uploads
• Light and dark appearance, Reduce Transparency and Increase Contrast support

Supported file types:
• Folders (lazy trees with icons, thumbnails, 500-item pages, and Back navigation)
• Source code (.cpp, .elrc, .ini, .js, .json, .py, .swift, .toml, .ttml, .yml and many more)
• Markdown (.md, .markdown, .mdown, .mkdn, .mkd, .Rmd, .qmd)
• Archive (.7z, .ear, .jar, .tar, .tar.gz, .tgz, .war, .zip)
• Jupyter Notebook (.ipynb)
• Tab-separated values (.tab, .tsv)
