## Agent skills

### Issue tracker

Track issues in GitHub Issues for `ranokay/glance`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the canonical `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix` labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout with `CONTEXT.md` at the root and ADRs under `docs/adr/`. See `docs/agents/domain.md`.

### Verification

Automated gates, manual capture convention, and exploratory-automation rules. See `docs/agents/verification.md`.
